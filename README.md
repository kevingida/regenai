# 🚀 RegenAI (Resume Generator AI)

**RegenAI** is a full-stack AI-powered SaaS application that helps users instantly generate ATS-optimized resumes and improve resume using AI.

Designed as a portfolio-grade project, it demonstrates modern full-stack engineering, AI integration, scalable architecture, and production-ready UI/UX.

## 🧠 Core Features

### 🪄 AI-Powered Resume Builder

- Generate professional resumes using AI
- Improve bullet points with measurable impact
- ATS score optimization
- Job-tailored suggestions

### 🌐 Portfolio Generator

- Instantly generate personal portfolio websites
- Multiple modern templates
- Public shareable URLs
- SEO optimized pages

### ✍️ Smart Editor

- Live resume preview
- Drag-and-drop sections
- Rich text editing support
- Auto-save functionality

### 🤖 AI Assistant

- Rewrite and improve content
- Generate summaries from raw input
- Suggest missing resume sections
- Keyword optimization for ATS systems

### 📊 Analytics Dashboard

- Resume views tracking
- Portfolio visits analytics

- Export resumes to PDF
